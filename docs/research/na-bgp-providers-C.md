# NA BGP VPS Providers — Batch C

Research goal: a **fully code-driven** second BGP provider alongside Vultr (North America only).

Verdict definitions:
- **FULLY-CODE-DRIVEN** = public compute API or Terraform provider **AND** BGP provisioned without a human ticket.
- **PARTIAL** = usable compute API but BGP is manual.
- **PANEL-ONLY** = no usable *public customer* compute API.

Researched 2026-09-11. Only APIs with real public docs are counted. VirtFusion's create/destroy API is real but is admin/operator-scoped and off-by-default for end users; a provider counts only if it documents/exposes a customer-usable path.

## Notes (one line each)

- **EasyVM** — Original brand appears deadpooled (assets reportedly sold to PureVoltage); domain now redirects to Aquatis.Host; note ASN in brief (AS26930) is the *upstream* Parallax, EasyVM's own is AS15287; nothing code-driven.
- **Elcro Digital** — VPS sold under lagless.gg (Elcro is the holding co.; network under nelexa.net); VirtFusion panel and free eBGP sessions advertised, but zero public API/BGP docs → panel/ticket only.
- **HYEHOST** — Strongest BGP story (self-service panel, no ticket claimed) but no HYEHOST-published compute API and a public "scammer" warning thread ([LET](https://lowendtalk.com/discussion/217750/)) — treat with caution; PARTIAL at best, not guaranteed code-driven.
- **iWebFusion** — Premise correction: iWebFusion (AS397373) is H4Y Technologies, **not** InterServer; InterServer is a separate company with a real SOAP/v2 API but that API does not apply here; BGP is a manual LOA/IRR/ROA engineering process.
- **Mean Servers** — SolusVM client panel only; the sole documented API is website-uptime monitoring; BGP is explicitly ticket + verifiable LOA + human RIR check.
- **Neptune Networks** — Nicest self-service BGP UX (RPKI/IRR-driven, no ticket) on a bespoke stack, but single NY site and **no** public compute API or TF provider, so compute cannot be code-driven; BGP is panel-driven + batch-applied twice daily, not programmatic.
- **SHIFT HOSTING** — Clean VirtFusion+WHMCS setup with well-documented BGP *policy/communities*, but the only real API (VirtFusion Global) is admin-only and not issued to customers; BGP turn-up is a $25 ticket.

## Bottom line

**Best fully-code-driven candidate: none.**

No provider in this batch meets FULLY-CODE-DRIVEN. Every one lacks a documented, customer-usable public compute API (VirtFusion shops keep the API admin-side; the rest have custom/SolusVM panels with none), and none exposes programmatic BGP session provisioning (no documented peer IP / peer ASN / MD5). The closest is **HYEHOST** (PARTIAL: self-service panel BGP with no claimed ticket, VirtFusion API underneath) — but its API is undocumented/unconfirmed for customers and it carries a public scam warning, so it is not a reliable code-driven choice. **Neptune Networks** has the best BGP self-service UX but no compute API at all (PANEL-ONLY, NY-only).
