# North America BGP VPS Providers — Batch D

Research goal: find a **fully code-driven** second BGP provider (alongside Vultr, North America only).
- **FULLY-CODE-DRIVEN** = public compute API (or a real Terraform/OpenTofu provider) that can create AND destroy a VPS, **AND** customer BGP/BYOIP provisionable without a human ticket.
- **PARTIAL** = usable public compute API exists, but BGP is manual (ticket/email).
- **PANEL-ONLY** = no usable public compute API.
- **N/A** = not North-America-located.

Date: 2026-09-11. Skeptical standard: an API only counts if real customer-facing docs exist.

## Notes

- **Panix** — Real, long-running NYC VPS product (V-Colo) with a cheap $25/mo BGP add-on, but the only interface is a proprietary web panel; no API, no Terraform, BGP is staff-provisioned.
- **Colorado Colo** — Not a VPS provider at all: colocation + bare-metal + IP transit. Custom Supabase portal, no compute API, sales-driven BGP.
- **Tritan Internet** — Custom Proxmox-backed platform with in-house open-source provisioning daemon, but no customer-facing API docs; BGP is free but requested via NOC email.
- **RackGenius** — Runs VirtFusion, whose end-user API can't create/destroy servers (admin-only); would be PARTIAL only if RackGenius handed customers an admin token, which is not offered. BGP is a manual NOC ticket.
- **Rackoona** — Has a real automated VPS product + custom dashboard, but its "API" is login-gated with zero public docs; no TF provider; BGP is a $100 one-time manual add-on.
- **Sunbreak Electronics** (brand: JeffColo) — Fundamentally colo/dedicated/IaaS; no self-service VPS, no API, human-provisioned BGP.
- **Ohz** (AS202673; correct site ohz.cloud — ohz.host does not resolve) — Only real NA self-serve VPS in this batch (Miami, from €4/mo), but WHMCS billing with an undisclosed VM panel, no public compute API, no Terraform, and BGP arranged by ticket only. PANEL-ONLY.
- **PP-Networks** (AS211358; store billing.ppnetworks.it, Proxmox panel control.ppnetworks.it) — Purchasable BGP VPS is "EUROPE Network" only; US presence is tunnel/IPv6-delegation and backbone/DDoS (NOCIX Kansas City, HE Fremont), no bookable NA VPS — so N/A. Even setting location aside it would be PANEL-ONLY (no API/TF; BGP sold as a manual config line item).

## Verdict for batch D

**No fully-code-driven candidate.** All North-America-located providers in this batch are PANEL-ONLY (Panix, Colorado Colo, Tritan, RackGenius, Rackoona, Sunbreak, Ohz); PP-Networks is N/A (Europe-only). None offers a documented public compute API to create/destroy a VPS combined with ticket-free BGP provisioning. Closest to a compute API is RackGenius (VirtFusion), but create/destroy is admin-scoped and not exposed to customers, and its BGP is a manual NOC ticket.
