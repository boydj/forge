# 0008. License: Apache-2.0

Date: 2026-09-10
Status: accepted

## Context

Public release. Candidates: Apache-2.0, MIT, AGPL-3.0.

## Decision

Apache-2.0: permissive, includes an explicit patent grant, widely understood by
operators who may self-host inside organisations. AGPL would discourage
self-hosting experimentation for little benefit to a project whose value is
in interoperable protocols rather than a hosted service.

## Consequences

- `LICENSE` at the root; per-file headers are not required.
- Contributions are accepted under the same license (see CONTRIBUTING.md).
